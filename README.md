DealPatch is an open-source, local-first CRM-style sales workspace built for learning, experimentation, and portfolio demonstration.

It explores how modern B2B sales software can combine:

- pipeline management
- accounts and contacts
- activity tracking
- review queues
- proposed CRM updates
- before/after diffs
- human approval
- optimistic updates
- undo and audit history
- keyboard-friendly workflows

## What this project demonstrates

DealPatch focuses on frontend engineering patterns used in data-dense business applications.

A core part of the project is the review workflow:


Activity
  ↓
Simulated analysis
  ↓
Proposed CRM change
  ↓
Human review
  ↓
Approve / Edit / Reject
