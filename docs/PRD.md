# DealPatch Product Requirements Document

## Product Overview

DealPatch is an open-source B2B sales workspace designed around
human-reviewed automation.

The application allows sales users to manage accounts, contacts,
deals, and activities while reviewing AI-style proposed CRM updates
through transparent before-and-after diffs.

DealPatch prioritizes interface trust, information density,
accessibility, perceived performance, and human control.

The V1 product runs entirely locally and requires no API keys,
environment variables, authentication, or external services.
